# Graph Theory: Educational Website

A small educational website (in Russian) about graph theory in programming, built with plain HTML and CSS as a school project.

## Pages
- Main page: Euler and the Konigsberg bridges, what a graph is
- Basic concepts and types of graphs
- Ways to store a graph (adjacency matrix, edge list, adjacency list) with a C++ example
- DFS and BFS with animations and code
- Additional information and sources

## Run locally
Open `index.html` in a browser, or serve the folder:
```bash
python3 -m http.server
```

Code highlighting uses [highlight.js](https://highlightjs.org/) 11.9.0 (BSD-3-Clause).
